# RaceDay Part 2

Open `RaceDay.sln` in Visual Studio 2022. The API is in `RaceDay.Api` and unit tests are in `RaceDay.Tests`.

The original Part 1 database script, ERD image, and endpoint plan are included in `Part1-Reference/`.

**Important:** Before assessment, run the project locally, create/update the database, run the tests, and verify the endpoints in Swagger. See `RaceDay.Api/README.md` for detailed setup instructions. The schema is mapped to the Part 1 entity/table names and relationships, but a local compile/test and lecturer-specific verification are still required.
